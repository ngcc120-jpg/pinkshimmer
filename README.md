# Pink Shimmer

Landing page adaptable para servicios de decoración y consultas de productos.

## Archivos

- `index.html`: estructura y contenido en español.
- `styles.css`: identidad visual, ilustraciones CSS y estilos responsive.
- `script.js`: navegación móvil, fecha mínima y envío de consultas a WhatsApp.
- `assets/`: imágenes de marca.

## Uso

Abre `index.html` en un navegador. No necesita instalar dependencias ni compilar.

Los formularios preparan un mensaje con la información del cliente y abren WhatsApp. El catálogo está presentado como una vitrina consultiva: para habilitar compra, carrito, inventario y pago faltan los productos, precios, reglas de envío y proveedor de pagos del negocio.
